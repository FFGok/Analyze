# Analyze V2

Multimodal AI analysis for images, PDFs, text and code.

## Render settings
- Build Command: `npm install`
- Start Command: `npm start`
- Environment variable: `OPENAI_API_KEY`
- Optional: `OPENAI_MODEL` (defaults to `gpt-5`)

## Important
- Keep the API key only in Render Environment Variables. Never put it in GitHub.
- AI-origin/authenticity and location results are estimates, not proof.
- Upload limit: 3 files, 15 MB each.

## Local run
```bash
npm install
cp .env.example .env
npm start
```
